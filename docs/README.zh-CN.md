# 肿瘤毒性评估工作台

用于作品集展示与模拟教学的浏览器应用，实现 **CTCAE v6.0（2025-07-22）** 中9种成人不良事件的部分标准。

[在线演示](https://ysm19990103.github.io/oncology-toxicity-workbench/) · [英文说明](../README.md) · [规则与来源](CLINICAL_RULES.md) · [验证记录](VALIDATION.md)

## 功能

- 6种实验室事件：中性粒细胞计数降低、贫血、ALT升高、AST升高、血胆红素升高、肌酐升高。
- 3种临床症状事件：腹泻、恶心、周围感觉神经病变。
- 显示分级依据、所用基线分支、规则版本及 NCI 原文页码。
- 未知信息保留为未知；缺失更高级别条件时不输出确定分级；未覆盖情况提示复核。
- 研究日/周期时间线、4个完全虚构的教学案例、中英文切换。
- JSON导入导出、评估CSV、独立日记CSV及打印报告。
- 自定义0–10分症状日记，与 CTCAE 评估完全分开，不是 PRO-CTCAE 量表。

## 本地运行

需要 Node.js 22或以上，无第三方包依赖，无API密钥。

```sh
npm run dev
npm test
npm run check
npm run build
```

测试套件有225项通过。引擎行覆盖率100%，分支覆盖率99.23%；不代表经过独立临床验证。

## 数据与范围

仅限模拟数据。无身份字段、日历日期、自由文本病历、后端数据库、追踪分析或账户。数据在浏览器内存中处理，刷新后清空；请先导出JSON保存。导入文件须符合严格结构，不能作为去标识化工具。

本项目不是 NCI 官方产品或经临床验证的医疗设备。不判断因果归因、SAE、用药剂量、治疗调整、DLT或器官衰竭。低级别不表示安全；“未符合标准”不是 CTCAE 0级。中性粒细胞分级不评估发热性中性粒细胞减少。

CTCAE v6.0 与 v5.0存在差异，应使用研究方案指定的版本。中文仅为非官方解释性界面，不是经验证的 CTCAE/PRO-CTCAE 译本；以 NCI 英文原文为准。
